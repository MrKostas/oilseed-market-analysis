# Расчёты DAX

Базовые DAX-меры преимущественно суммируют показатели; сложность кейса находится в зерне фактов, связях и аналитических взаимодействиях.

Для экспорта шротов KPI использует региональный факт, а график — заводской. Их совпадение не задано автоматически и требует сверки покрытия.

## Объекты модели

Меры, вычисляемые таблицы и столбцы разделены. Для меры/столбца таблица назначения важна: имя файла её не заменяет. Служебные автоматические календари не экспортировались. Выражения взяты из метаданных, а не восстановлены по изображениям.
