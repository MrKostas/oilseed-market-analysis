# Как читать и восстановить проект

## Просмотр без закрытых данных

1. Открыть README и галерею настоящих экранов, затем схему модели и технические пояснения.
2. Прочитать выражения M и DAX; индексы сохраняют имена объектов и разделяют этапы подготовки.
3. Использовать VALIDATION.md как сценарий технического разбора. Для просмотра кода Excel и Power BI не нужны.

## Восстановление в разрешённой среде

Потребуются Excel с Power Query для подготовительных книг, Power BI Desktop для модели и исходные формы/справочники с нужными именами листов, таблиц, столбцов и типами. Точные версии приложений исходного проекта не зафиксированы. В repository есть значения на снимках экранов, но нет исходных таблиц, PBIX, PBIT или готового развёртывания; одного клонирования недостаточно для Refresh.

1. Восстановить первичные формы законным способом либо подготовить совместимые самостоятельные демонстрационные данные. Не подменять их произвольной таблицей без проверки контракта.
2. Создать нужные подготовительные Excel-книги. Импортировать выражения из `src/power-query/source/` как отдельные запросы с именами из query-index.csv. В Advanced Editor вставлять содержимое отдельного .m файла, а не имя файла.
3. Создать используемые на этом этапе параметры из `parameters/`, указать свои локальные пути и добавить необходимые таблицы Excel.CurrentWorkbook. Создать все зависимые запросы до Refresh. Для источника мониторинга нужны таблица полей и Найти/Заменить с согласованным порядком/именами; реальные строки справочников не поставляются.
4. Загрузить результаты в промежуточные книги с именами Excel Tables, ожидаемыми M-кодом `model`. Форматы/поля задаются самими выражениями. Запрос с одинаковым именем в Excel и Power BI относится к разным этапам.
5. В новом Power BI-файле создать M-запросы из `model/` и параметры, направленные на промежуточные книги, справочники и карту. Проверить типы, уникальность ключей, полноту фактов и отсутствие размножения сумм.
6. Создать связи по ARCHITECTURE.md / relationships.csv, затем вычисляемые таблицы, столбцы и меры DAX в указанных таблицах назначения. Служебные Auto date/time не следует импортировать как бизнес-объекты.
7. Настроить страницы, взаимодействия, bookmarks и навигацию по REPORT_GUIDE.md. SVG показывает компоновку, но не является импортируемым Power BI-layout и не восстанавливает визуалы автоматически.
8. Выполнить проверки VALIDATION.md и записать фактические результаты. Если используется другая версия/locale, проверить формат дат и поддержку визуалов отдельно.

Параметризация путей не исправляет исходные формулы и не гарантирует успешного Refresh. Лицензирование географической подложки/иконок и любых новых данных проверяется отдельно.
