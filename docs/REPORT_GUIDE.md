# Интерфейс и сценарий анализа

Начать знакомство с выполненной работой можно с [галереи настоящих экранов](GALLERY.md): в ней показаны исходные состояния и примеры выбора срезов.

Число объектов включает наложенные визуалы, переключаемые bookmarks; оно не равно числу одновременно видимых графиков. Страница Методика описывает регламент, но не доказывает расписание Refresh в Service.

## Пользовательские механики из описания проекта

Листы "Рынок масличных в РФ", "Рынок растительных масел в РФ" и "Рынок растительных шротов в РФ"

Фильтрация данных и изменение показателей осуществляются путем взаимодействия пользователя с фильтрами "Вид сырья" и "Сезон", а также - с таблицей .
Таблица представляет собой одновременно и самостоятельный визуальный элемент (содержащий данные по производству масла по заводам и по потреблению на фасовку, майонез и спец. жиры в разрезе регионов и заводов), и фильтр.
Для детализации показателей кликните по значку "+" у интересующего показателя. Если есть необходимость изучить информацию в разрезе регионов/холдингов/заводов, то необходимо кликнуть на индикатор в виде двух направленных вниз стрелок (данный индикатор появляется при наведении курсора мыши на таблицу).
В случае, если пользователь хочет отфильтровать информацию на листе по конкретному региону/холдингу/заводу, то необходимо кликнуть по любой ячейке в строке с показателем. 
Детализация графиков происходит по следующему пути: «Сезон» – «Год» – «Месяц». Если детализация не активна, то наведите курсор на график и в появившейся панели в правом верхнем углу визуализации нажмите на индикатор «стрелка, направленная вниз» - вы включите режим детализации.

## Bookmarks и навигация

- Bookmark `Сброс фильтров_масло`.
- Bookmark `Сброс фильтров_шрот`.

- Bookmark `Показ импорта_сырье`.
- Bookmark `Показ переработки_сырье`.
- Bookmark `Полноэкранный_сырье`.
- Bookmark `Полноэкранный_масло`.
- Bookmark `Полноэкранный_шрот`.

В Layout сохранены индивидуальные настройки взаимодействий между визуалами. Их наличие подтверждено, но направление фильтрации / подсветки каждой пары не проверялось кликами. Объекты `singleVisualGroup` — группы оформления и переключаемых блоков, а не DAX calculation groups. Используются текстовые блоки, изображения, кнопки и фирменное оформление; они не образуют дополнительные таблицы модели.

## Демонстрационные материалы

В [галерею](GALLERY.md) включены 3 настоящих PNG из авторской подборки. Видимые состояния проверены по изображениям; при копировании пиксели, значения, контакты и оформление не менялись. Имя no filters трактуется как название файла: сохранённый сезон и другие видимые выборы указаны в подписи.

[Схемы компоновки](LAYOUTS.md) в SVG сохранены как дополнительная техническая иллюстрация по координатам и типам visualContainers. Это не снимки работающего отчёта. Отдельные файлы карт, логотипов и иконок из PBIX не извлекались для распространения; они могут быть видны в составе исходных PNG.
